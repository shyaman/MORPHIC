# Release verification

Checked on 5 November 2026. These checks cover the final-model release, not every manuscript experiment. No full retraining or complete 35-slide rescore was performed during this update. No CUDA device was available on the verification node.

## Passed

- **Environment:** `uv sync --frozen` installed the locked dependencies into a fresh Python 3.12 environment. Inference, preprocessing, the training smoke test, and metric checks ran in that environment.
- **Download availability:** all 390 expected paths for the 78 slides exist at HEST revision `7e8d5a0b0aace41d8c8ec0f6ecea80e4ad2a61ec`. This was a repository-file listing check, not a fresh full-cohort download. UNI2-h weights were available locally and hash-checked.
- **Checkpoint:** the copied file's SHA256 is `4871703f1fa58bf29cf6e4508cb03a1ec19d73f3d8dc35fac2d70bf236f96ecc`. It is the original paper checkpoint, selected epoch 3 (one-based), with no conversion or calibration.
- **Raw-data preprocessing:** TENX132 reproduced all 5,958 cells, 27,858 directed pairs, and sparse targets exactly against the saved research cache. TENX122 reproduced 17,031 cells, 162,626 directed pairs, and the original shard boundary at directed pair 100,001. Its targets exactly match targets regenerated by the original research implementation in the same environment. Compared with the historical saved targets, both implementations differ by at most `1.1920929e-7`; no binary labels changed. These are float32 target differences, not cell-pair selection or transcript-count differences.
- **Sampling and training math:** original and release initialization, epoch cell-pair ordering (including multiple shards and reverse-direction pair retrieval), validation pair selection, hard-mixture cases, and direction cases match. A representative combined loss was identical (`0.7363868355751038`); maximum gradient difference against the original optimized computation was `4.66e-10`. The release uses the same shared role-parameter computation for training.
- **Training command:** a one-epoch CPU smoke test with tiny neighboring-cell-pair fixtures under all 37 training and six validation sample names visited all 296 fixture training pairs and wrote the configuration, history, and reloadable best checkpoint. This is an execution check, not a real-cohort training result.
- **Images and encoder:** crops, nucleus masks, and CPU UNI2-h nucleus embeddings for two real TENX132 cells match the original implementation exactly. Historical CUDA bfloat16 embeddings were not regenerated on this CPU node.
- **New-image inference:** the supplied synthetic image, nuclei, and annotations ran through `uv run --frozen --offline python scripts/infer.py` with 50% sampling. All eight annotations matched; score and provenance outputs were written. Automatic segmentation was not rerun during this update.
- **Checkpoint-selection validation:** using the original cached features for all six validation slides, the release recomputed Brier as `0.003914854421921698`, versus `0.0039148543718361675` stored in the checkpoint (difference `5.01e-11`).
- **Held-out evaluation:** the complete NCBI876 evaluation command ran on 173,440 directed pairs and 74 measured mechanisms. Using saved reference scores, AUROC, AP, and sender AP excess reproduce all 59 benchmark-eligible mechanisms within `1e-12`. Newly computed CPU scores versus historical GPU scores gave maximum per-mechanism metric differences of `3.46e-6` (AUROC), `3.02e-7` (AP), and `1.17e-6` (sender AP excess).
- **Grouping:** regrouping the saved 35-slide MORPHIC benchmark results with the conservative shared GSE315411 TMA block produces 26 groups: mean AUROC `0.7205315323`, AP `0.0335362017`, and sender AP excess `0.0884961376`. These are recalculated aggregates of saved results, not results from a new 35-slide scoring run. The original workbook remains unchanged.

## Reproduction scope

The README supplies the download → preprocessing → training → evaluation commands. Rebuilding every feature cache, rerunning the full training epoch sequence over 134,091,002 directed pairs, and rescoring all held-out slides still require substantial compute and storage. Numerical equality across GPU architectures and library/kernel versions is not guaranteed; the included checkpoint itself is byte-identical to the paper artifact.

The frozen cohort retains the original donor/source assignments except the explicit conservative TMA correction. Unresolved donor/core identities remain unresolved. Baselines, ablations, lung-specific analysis, and survival analysis are outside this release update.
